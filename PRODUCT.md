# Product

## Register

product

## Users

Solo user (owner) running a self-hosted RAG on a homelab. Uploads PDFs and images, organizes them into groups, chats with them via public-facing endpoints. Technical enough to self-host; primary task on any screen is "get an answer fast from my documents."

## Product Purpose

RAGO is a private, self-hosted document intelligence tool. Users upload documents (PDF, scanned, image), which are processed via OCR + embedding and stored in a vector database. Groups expose a public chat interface so others can query documents without an account. Success = a question answered that the user couldn't have answered without searching through files manually.

## Brand Personality

Bold · Expresivo · Distinto. Strong opinions in the UI — heavy borders, lime green that punches, hard offset shadows. Not a "tool that gets out of the way"; a tool with character that the owner is proud to run. Playful confidence, not corporate polish.

## Anti-references

- SaaS-gray (Notion, Linear, ClickUp): rounded-everything, gray-on-gray, endless soft shadows
- Enterprise dashboard blue (Datadog, Grafana default): dark sidebars, chart-first, data-dense navy
- AI-startup cream/beige: warm paper-toned backgrounds, whisper-weight type
- Ultra-minimal Japanese quiet: so much whitespace it has no personality

## Design Principles

1. **Character is load-bearing.** The lime + hard shadow + bold type IS the product identity. Don't neutralize it to look "professional."
2. **Clarity over cleverness.** User is alone, mid-task, wants the number or the answer. Labels must be literal. No metaphors.
3. **Dense but not cramped.** Homelab tool; screen real estate is for data, not breathing room. Padding earns its space.
4. **Feedback is immediate.** Status (pending/processing/done/failed) must be impossible to miss. No ambiguous states.
5. **Self-hosted pride.** The UI should feel like something worth showing off, not a throwaway internal tool.

## Accessibility & Inclusion

Single user, self-hosted, no formal WCAG requirement. Maintain ≥4.5:1 body text contrast and ≥3:1 large text. No reduced-motion support required but don't make motion the gatekeeper for content visibility.
